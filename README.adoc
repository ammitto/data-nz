= Ammitto New Zealand Russia sanctions data

image:https://github.com/ammitto/data-nz/actions/workflows/fetch.yml/badge.svg["Fetch Data", link="https://github.com/ammitto/data-nz/actions/workflows/fetch.yml"]

This repository stores New Zealand's Russia Sanctions Register as YAML for
Ammitto. The records in `processed/` cover individuals, entities and ships
listed by the Ministry of Foreign Affairs and Trade (MFAT).

== Source

* Publisher: Ministry of Foreign Affairs and Trade (MFAT), New Zealand
* List page: https://www.mfat.govt.nz/en/countries-and-regions/europe/ukraine/russian-invasion-of-ukraine/sanctions/russia-sanctions-register
* File downloaded: https://www.mfat.govt.nz/assets/Countries-and-Regions/Europe/Ukraine/Russia-Sanctions-Register.xlsx

The register gives details of designations made under the Russia Sanctions
Regulations 2022.

== Contents

`processed/` holds one file per designation, named after the register's
unique identifier: `processed/nz-ind-100.yaml` is `IND-100`. Identifiers start
with `IND` for individuals, `ENT` for entities and `SHP` for ships.

`processed/_index.yaml` lists every file, with the time of the last fetch.

The keys are the register's columns, each present only when the register
gives a value. Yes or no columns are kept as the text published (`Yes`,
`No`, and sometimes lower case).

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `type` | string | `Individual`, `Entity` or `Ship`
| `unique_identifier` | string | Register identifier, such as `IND-100`
| `first_name`, `middle_names`, `last_name` | string | Individuals: name
| `name` | string | Entities and ships: name
| `alias_alternate_spellings` | string | Other spellings of the name
| `alias_alternate_names` | string | Ships: other names
| `title` | string | Individuals: position or title
| `dob` | string | Individuals: date of birth, `YYYY-MM-DD`
| `place_of_birth` | string | Individuals: place of birth
| `citizenship`, `citizenship_2`, `citizenship_3` | string | Individuals: citizenships
| `passport_number` | string | Individuals: passport numbers
| `associates_relatives` | string | Individuals: stated family or business links
| `address` | string | Address
| `imo_number` | string | Ships: IMO number
| `sanction_status` | string | Status in the register, such as `Sanctioned`
| `date_of_sanction` | string | Date of designation, `YYYY-MM-DD`
| `date_of_additional_sanction` | string | Date further sanctions were added
| `travel_ban`, `asset_freeze`, `aircraft_ban`, `ship_ban`, `service_prohibition`, `dealing_with_securities` | string | Whether each measure applies
| `general_rationale_for_sanction` | string | Reason given for the designation
|===

== Using the data

Clone or download this repository and run either example from its root
directory.

Ruby:

[source,ruby]
----
require "yaml"

Dir.glob("processed/nz-*.yaml").sort.each do |path|
  record = YAML.safe_load_file(path)
  name = record["name"] ||
         [record["first_name"], record["middle_names"], record["last_name"]].compact.join(" ")
  puts [record["unique_identifier"], record["type"], record["date_of_sanction"], name].join("\t")
end
----

Python (requires PyYAML, installed with `python3 -m pip install PyYAML`):

[source,python]
----
import glob
import yaml

for path in sorted(glob.glob("processed/nz-*.yaml")):
    with open(path, encoding="utf-8") as f:
        record = yaml.safe_load(f)
    name = record.get("name") or " ".join(
        record[key] for key in ("first_name", "middle_names", "last_name") if record.get(key)
    )
    print(record["unique_identifier"], record["type"], record["date_of_sanction"], name, sep="\t")
----

The same register, harmonized with the other sources into JSON-LD:
https://www.ammitto.org/api/v1/sources/nz.jsonld

== Updates

The `Fetch Data` workflow (`.github/workflows/fetch.yml`) downloads the
register every day at 06:00 UTC and commits any change to `processed/`. It
runs with `--prune`, so a designation MFAT has removed is deleted here on the
next fetch.

== Development

`processed/` is generated by the Ammitto gem. To refresh it locally, use
Ruby 3.4 (the version selected by the fetch workflow) and Bundler. From
the repository root, run:

[source,shell]
----
bundle install
bundle exec ammitto fetch nz --format yaml --output-dir processed --verbose --prune
----

`--prune` removes files for listings no longer present in the fetched list.
Review the generated changes before committing them.

Fetch and parser changes belong in the
https://github.com/ammitto/ammitto[Ammitto gem]; its source models are in
https://github.com/ammitto/ammitto/tree/main/lib/ammitto/sources/nz[`lib/ammitto/sources/nz/`].
Report data or source-list issues in
https://github.com/ammitto/data-nz/issues[this repository].
